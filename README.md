# Mini SOC Lab

## About

This project documents the development of a Security Operations Center (SOC)
laboratory focused on security monitoring, log analysis and incident investigation.

The lab uses virtual machines to simulate a small monitored environment and
investigate security events in a controlled environment.

## Objectives

- Practice security monitoring
- Analyze security logs
- Learn SIEM concepts
- Investigate security alerts
- Practice incident response
- Document security investigations

## Technologies

- Wazuh
- Linux
- VirtualBox
- SIEM
- Security Event Logs
